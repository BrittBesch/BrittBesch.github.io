# personal website

A minimal static site in a plain serif style. Three pages: home, news and CV.
Published with GitHub Pages at https://brittbesch.github.io

## Files
- `index.html` – home (photo, name, short bio, links)
- `news.html` – news feed
- `path.html` – CV: education, experience, selected awards
- `styles.css` – styling
- `favicon.svg` – browser-tab icon
- `photo.jpg` – portrait used on the home page
- `sitemap.xml` – for search engines (update `sitemap.xml` when adding pages)
- `google3c9805b9094e5a5c.html` – Google Search Console verification (don't delete)
